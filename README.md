# HTML Course Website 🚀

This is my **first deployed HTML-only project**, created to practice basic web development concepts using **pure HTML**. The website represents a simple **course 
selling and learning platform** with multiple pages connected using hyperlinks.

## 📌 Project Overview

This project is a static website built using only **HTML**, without CSS or JavaScript. It contains multiple pages such as Home, Courses, Contact, and About, 
demonstrating page navigation, images, forms, and embedded video thumbnails.

* HTML page structure
* Linking multiple HTML pages
* Using images and forms
* Basic website layout
* First-time deployment experience

## 📄 Pages Included

### 🏠 Home Page

* Introduction to the website
* Navigation menu (Home, Courses, Contact Us, About Us)
* Course promotion section
* Copyright section

### 📚 Courses Page

* Web Development free video section
* DSA course section
* Course thumbnails (YouTube-style images)
* Organized course display


### ℹ️ About Page

* Information about the tutor
* Tutor introduction section
* Embedded course image

## 🧭 Navigation

All pages are connected using **HTML anchor (****`<a>`****) tags**, allowing smooth navigation between pages.
